### Task 3: Reorganize CurrentTabCard Layout

**Files:**

- Modify: `components/CurrentTabCard.tsx`

**Step 1: Move Content from Secondary to Primary**

Reorganize the component so that `LayerCard.Secondary` only contains the status text and the Read/Unread badge. Move the Title, Favicon, URL, Description, and Tags into `LayerCard.Primary`.

```tsx
// components/CurrentTabCard.tsx reorganization structure:
<LayerCard>
  <LayerCard.Secondary className="flex items-center justify-between pb-1">
    <div className="uppercase tracking-wide">
      <Text variant="secondary" size="xs">
        {isBookmarked ? 'Current page in Linkding' : 'Not in Linkding'}
      </Text>
    </div>
    {isBookmarked && (
      <Badge
        variant={bookmark.unread ? 'primary' : 'secondary'}
        className="..."
      >
        {bookmark.unread ? 'Unread' : 'Read'}
      </Badge>
    )}
  </LayerCard.Secondary>
  <LayerCard.Primary className="pt-3 pb-3">
    <div className="flex items-center gap-1.5 mb-2">
      <BookmarkFavicon url={favicon} />
      <div className="line-clamp-1">
        <Text variant="body" size="sm" bold>
          {title}
        </Text>
      </div>
    </div>
    {/* URL, Description, Tags, Preview Image, and Actions follow in Primary */}
  </LayerCard.Primary>
</LayerCard>
```
